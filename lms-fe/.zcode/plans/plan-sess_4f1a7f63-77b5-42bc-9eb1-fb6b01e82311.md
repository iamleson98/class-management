# Major Feature Overhaul Plan — Việt Mỹ Global LMS

## Overview
Comprehensive feature overhaul covering: primary color change (emerald → sky blue + orange), bilingual EN/VN, student info updates, student/parent view enhancements, class detail view, tuition management redesign, and new models for reviews/ratings/homework.

---

## Phase 1: Primary Color Change (Sky Blue + Orange)

Replace all `emerald-*` Tailwind classes across ~25 component files with `sky-*` (primary) and `orange-*` (accent). Update globals.css scrollbar, selection, custom utilities.

**Color mapping:**
- `emerald-500/600/700` → `sky-500/600/700` (buttons, links, text)
- `emerald-50/100/950` → `sky-50/100/950` (background tints)
- Gradients: mix of `sky-*` and `orange-*` for brand identity
- Orange (`orange-500/600`) for CTAs, warnings, highlights

**Files:** globals.css, home/page.tsx, courses/page.tsx, page.tsx (admin shell), lms-store.ts, all admin/role component files (~25 files)

---

## Phase 2: Bilingual English-Vietnamese

Lightweight custom i18n (no heavy library). Translation JSON files + React context.

**New files:**
- `src/lib/i18n/locales/vi.ts` — Vietnamese translations
- `src/lib/i18n/locales/en.ts` — English translations
- `src/lib/i18n/context.tsx` — LanguageProvider + `useTranslation()` hook
- `src/lib/i18n/index.ts` — Barrel export

**Pattern:** `const { t, locale, setLocale } = useTranslation()` → `t('nav.dashboard')`
**Persistence:** localStorage key `vmg-lang`

**Modified:** page.tsx (admin shell), public layout, all admin/role components, all public pages (~20+ files)

---

## Phase 3: Student Info Changes

### API (`api/students/`):
- Accept/return new fields

## Phase 4: Student/Parent View Enhancements (LARGEST PHASE)

### 4a. New DB Models:
- **WeeklyReview** — studentId, classId, weekNumber, content, rating(1-5), createdBy
- **Homework** — title, description, fileUrl, sessionId?, classId, courseId, teacherId, deadline
- **HomeworkSubmission** — homeworkId, studentId, fileUrl, grade, feedback, submittedAt, gradedAt
- **ClassMedia** — classId, sessionId?, title?, fileUrl, fileType(PHOTO/VIDEO), uploadedById

### 4b. New API Routes:
- `/api/homework` — GET (filter by class/student), POST
- `/api/homework/[id]` — GET, PUT, DELETE
- `/api/homework/[id]/submissions` — GET, POST
- `/api/homework/bulk-assign` — POST (one homework → many students)
- `/api/weekly-reviews` — GET, POST
- `/api/weekly-reviews/[id]` — GET, PUT, DELETE
- `/api/class-media` — GET, POST
- `/api/class-media/[id]` — DELETE

### 4c. New Zod Schemas:
- `homework.schema.ts` — createHomework, bulkAssign, homeworkSubmission
- `weekly-review.schema.ts` — createWeeklyReview
- `class-media.schema.ts` — createClassMedia

### 4d. Enhanced Student Dashboard:
- Course progress (start date, end date, sessions attended/remaining)
- Weekly reviews with ratings
- Test scores / grading updates
- Homework list with status (pending/submitted/graded)

### 4e. Enhanced Parent Dashboard:
- Child's course progress + attendance
- Weekly reviews visibility
- Homework visibility
- Class photos/videos gallery

### 4f. New Components (~7 files):
- `student/reviews.tsx`, `student/homework.tsx`
- `parent/reviews.tsx`, `parent/homework.tsx`, `parent/media.tsx`
- `admin/homework.tsx`, `admin/reviews.tsx`

### 4g. Admin Shell (page.tsx):
- Add `reviews`, `homework` to STUDENT_NAV
- Add `reviews`, `homework`, `media` to PARENT_NAV
- Add `homework`, `reviews` to TEACHER_NAV

## Phase 6: Tuition Management Redesign

### DB Changes:
- New `AdditionalFee` model: tuitionId, label (Bán trú/Trông muộn/Đưa đón/Nội trú/Tài liệu/Đồng phục), amount
- Add to Tuition: `discountType` (PERCENT/FIXED_VND), `discountValue`, `promotionalFee`

### Redesigned Tuition Dialog:
1. **Student Selection** — Search by name/code → dropdown with matching students
2. **Học phí gốc** — Original fee
3. **Thêm phí khác** — Dynamic rows with dropdown (Bán trú, Trông muộn, Đưa đón, Nội trú, Tài liệu, Đồng phục) + amount
4. **Tổng phí** — Auto-calculated
5. **Giảm giá** — Toggle % or VND, enter value
6. **Học phí ưu đãi** — Auto = Total - Discount
7. **Hạn thanh toán** — Date picker
8. **Summary Display** — Visual breakdown

**Files:** prisma/schema.prisma, tuition.schema.ts, api/tuitions/*, admin/tuition.tsx
