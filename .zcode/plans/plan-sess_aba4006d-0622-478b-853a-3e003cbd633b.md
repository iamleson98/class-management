## Goal
Add 7 features, porting the old chat's patterns into the new chat (`lms-fe/src/components/lms/chat/` + `lms-fe/src/lib/chat/`):

1. **Threading (full, incl. global inbox)** — follow/unfollow, live unread/mention tracking, mark-read gating, global "Threads" RHS panel.
2. **Realtime channel messaging** — confirm/fix live message delivery (posts appear in realtime for all channel members).
3. **Presence (online/offline/away)** — poll + focus/blur server push.
4. **Special mentions** — `@channel`/`@all`/`@here` in the composer autocomplete.
5. **Channel bookmarks** — add edit + file bookmarks + reorder (dot menu).
6. **Accessibility** — aria-labels, aria-live new-message region, keyboard-focusable posts.
7. **Notification sound** — bundled default mp3, throttled.
8. **Channel header actions** — copy link, mute/unmute, toggle favorite, add members (menu).

## 1. Threading (the big one) — store + hooks + WS + UI

**New `src/lib/chat/threads.ts`** — thread types + helpers:
- `ChatThread` type (ports `UserThread`): `{ id, reply_count, last_reply_at, last_viewed_at, participants, unread_replies, unread_mentions, is_following, post: { channel_id, user_id } }`.
- `threadIsSynthetic(thread)` helper.

**`store.ts`** — add a `threads` slice:
- `threadsById: Record<threadId, ChatThread>`
- `threadsInTeam: Record<teamId, threadId[]>` (following, sorted by last_reply_at desc)
- `unreadThreadsInTeam: Record<teamId, Set<threadId>>`
- `threadCounts: Record<teamId, { total, total_unread_threads, total_unread_mentions }>`
- `manuallyUnreadThreads: Set<threadId>` (Alt-click to keep unread)
- Actions: `receiveThread`, `receiveThreads(teamId, threads, counts?)`, `setThreadFollow(threadId, following)`, `setThreadReadState(threadId, {unread_replies, unread_mentions, last_viewed_at})`, `setThreadCounts(teamId, counts)`, `markAllThreadsRead(teamId)`, `toggleManuallyUnread(threadId)`.

**`hooks.ts`** — new thread hooks (thin Client4 wrappers, optimistic like the old `setThreadFollow`):
- `useUserThreads(teamId, { unread })` → `client4.getUserThreads('me', teamId, { perPage: 25, extended: true, threadsOnly: true, unread })` → `receiveThreads`.
- `useThreadCounts(teamId)` → `getUserThreads(..., { totalsOnly: true })` → `setThreadCounts`.
- `useFollowThread(teamId)` → optimistic `setThreadFollow` flip → `client4.updateThreadFollowForUser` → refetch counts.
- `useMarkThreadRead(teamId)` → gated call to `updateThreadReadForUser` (only if `last_viewed_at < last_reply_at || unread_mentions || unread_replies`).
- `useThreadWithReplies(rootId)` — enhance existing `useThread` to also fetch+store the thread metadata via `getUserThread`.

**`websocket-events.ts`** — handle the 3 thread WS events (JSON.parse the `data.thread` string; read `broadcast.team_id`):
- `thread_updated` → `receiveThread` (force `is_following=true` if current user is root author); if thread is currently open + window focused + not manually unread, zero unreads + call `updateThreadRead`.
- `thread_follow_changed` → `setThreadFollow(threadId, state)`.
- `thread_read_changed` → union-discriminated: single-thread → `setThreadReadState`; all-in-team → `markAllThreadsRead`.

**New `src/components/lms/chat/threads-inbox.tsx`** — global Threads RHS panel:
- Two lists: "All" + "Unread" (filter chips), sorted by `last_reply_at` desc.
- Cursor pagination via `before` (oldest loaded thread id).
- Each item: root-post preview, participant avatars, reply count, last-reply timestamp, unread dot / mention badge, thread menu (follow/unfollow, mark read/unread).
- Header shows `counts.total_unread_threads`.

**`thread-view.tsx`** — enhance:
- Add a **Follow/Unfollow button** (optimistic via `useFollowThread`).
- Mark-thread-read on open (gated).
- Show unread-replies indicator.

**`post-list.tsx`** — thread-root footer: show unread dot (when `is_following && unread_replies`) + mention badge (when `unread_mentions`) next to the existing reply count. Uses a `threadsById[postId]` lookup (falls back to synthetic from the post's reply_count).

**`chat-view.tsx`** — add `'threads'` to the RHS union + a header button to open the global inbox (with the unread-threads count badge).

**Realtime messaging (item 2)**: the existing `posted` WS event already upserts posts into the store and the post list re-renders. I'll verify the active-channel skip logic doesn't drop the current user's *own* outgoing post or messages sent while the channel is open, and ensure the post list auto-scrolls on live posts. No new infra needed — this is a verification + minor fix pass.

## 2. Presence (poll + focus/blur)

**`hooks.ts`** — `usePresencePoll(channelId)`: collects visible user ids (recent posters in channel + DM partners + self) and calls `getStatusesByIds` every 60s. Wires into chat-view for the active channel.

**New `src/lib/chat/use-presence-sync.ts`** — focus/blur → `wsClient.userUpdateActiveStatus(active, false)`: on window focus push 'online'; on blur, push 'away' (after a short idle threshold, mirroring old behavior). Respects manual DND status (won't override).

## 3. Special mentions in composer

**`post-composer.tsx`** — when the mention query is open with a prefix, prepend hardcoded `@channel`/`@all`/`@here` suggestions (filtered by `startsWith(prefix)`) to the mention results list, before the user matches. Rendered with the broadcast styling. Selecting inserts `@name `.

## 4. Channel bookmarks (edit + file + reorder)

**`hooks.ts`** — add `useUpdateBookmark` (`updateChannelBookmark`) and `useReorderBookmark` (`updateChannelBookmarkSortOrder`).
**`channel-bookmarks.tsx`** — add a per-bookmark dot menu (edit opens a popover with name/emoji fields; delete). Add a "file" bookmark type in the create modal (upload via `uploadFile`, store `file_id`). Render file bookmarks with a download link. Keep it link+file (no board type).

## 5. Accessibility

**`post-list.tsx`** — add `aria-label="message list"` + `role="log"` on the scroll container; `aria-label="More"` on the post-menu trigger; an `aria-live="polite"` sr-only region announcing the latest post. Make `PostRow` keyboard-focusable (`tabIndex={0}`, `role="article"`).

## 6. Notification sound

**`public/sounds/bing.mp3`** — add a small default notification sound asset.
**`notifications.ts`** — `playSound()` uses `/sounds/bing.mp3`, throttled to 1 ding / 3s (matching old `ding()`). Remove the config-gated no-op.

## 7. Channel header actions

**`chat-view.tsx` header** — add a dropdown menu (Popover) on the settings icon: **Copy link** (permalink `${origin}/pl/...` or channel URL), **Mute/Unmute** (`updateChannelNotifyProps` → `mark_unread: 'mention'|'all'`), **Favorite/Unfavorite** (existing `useToggleFavorite`), **Add members** (opens a members invite modal — minimal: search users + `addUserToChannel`).
